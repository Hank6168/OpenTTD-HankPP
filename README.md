## 简介

本项目是基于 **OpenTTD-JGRPP** 开发的偏中式扩展版本。

主要面向中式运输与铁路建设玩法，在保留 JGRPP 原有玩法的基础上，
进一步扩展：

- 城市发展模拟
- 土地价值系统
- 建筑实际人口
- 住宅入住率
- 城际经济联系与客流
- 铁路运营相关机制
- 中式车站信息显示

长期目标是在 JGRPP 原有基础上，
逐步形成一个更符合 **中国铁路与本土化玩法** 的游戏环境，

遇到任何问题，欢迎通过 Issue 或项目开发交流群反馈

HankPP 开发交流群：1074303090

# 主要功能

## 🏙 城市与土地价值

HankPP 加入了独立的城市土地价值体系，
为后续城市发展及相关经济机制提供基础。

目前包括：

- 城市土地价值评分
- 基于距离的地价衰减
- 土地价值缓存机制
- 月度土地价值更新
- 土地价值相关经济影响
- 城市内部区域地价差异

后续也会与城市发展、人口，建筑及交通条件等机制进行联动。


## 🏘 建筑与人口

对原建筑容量进行扩展，使建筑规模与实际居住人口之间具有更合理的关系。

目前包括：

- 建筑实际人口计算
- 住宅入住率
- 不同建筑类型的人口差异
- 城市实际人口统计
- 住宅与其他建筑识别


## 🌆 城市发展模型

在原有城市增长机制上进一步加入发展需求、住宅密度及区域发展等因素。

目前包括：

- 城市发展需求计算
- 住宅密度调整
- 区域发展影响
- 城市增长模拟
- 城市规模与发展水平联动

## 🌐 城际经济与客流联系

尝试建立经济发达地区之间的长途出行需求。

目前考虑方面：

- 城市人口
- 城市发展水平
- 城市间距离
- 距离衰减
- 城际经济联系
- 城际走廊
- 城际客流需求

想法是使人口规模较大、发展程度较高，
且距离较为合理的城市之间形成更加明显的城际联系与客流走廊，类似京沪高铁。


## 🚄 铁路运营扩展

目前及后续方向包括：

- 线路运营信息
- 列车运行相关数据
- 城际运输走廊
- 线路开通与运营历史
- 客流观测与运输反馈
- 中式铁路运营相关功能

## 中式本土化扩展

逐步将国内相关内容加入至游戏当中。

包括：

- 中文界面与信息显示优化
- 中式车站大屏
- 更贴近国内铁路的车次显示
