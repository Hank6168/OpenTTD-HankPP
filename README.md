## 简介

本项目是基于 **OpenTTD-JGRPP** 开发的偏中式扩展版本。

主要面向于中式运输与铁路建设玩法，在保留 JGRPP 绝大多数玩法的基础上，
进一步扩展了：

- 城市发展模拟
- 土地价值系统
- 建筑实际人口
- 住宅入住率
- 城际经济联系与客流
- 铁路运营相关机制
- 中式列车运行交路

目标是在 JGRPP 原有的基础上，
逐步打造一个更接近 **中国铁路与本土化玩法** 的游戏，

HankPP 开发交流群：1074303090

# 主要功能

## 城市与土地价值

HankPP 加入了独立的城市地价体系，
为后续城市发展及相关经济机制拓展提供了基础。

目前包括：

- 城市地价评分
- 基于多方面考量的地价
- 月度地价更新
- 地价引起的经济影响

后续也会与城市发展、人口，建筑及交通条件等机制进行联动。


## 建筑与人口

HankPP 对原版及部分GRF建筑的容量进行扩展，使建筑规模与居住人口实现更合理的关系。

目前包括：

- 建筑实际人口计算
- 住宅入住率
- 城市实际人口统计
- 识别建筑,商业与工业建筑等


##  城市发展优化

在原城市增长机制上进一步加入了发展需求、住宅密度及区域发展等因素。

目前包括：

- 城市发展需求计算
- 住宅密度调整
- 区域发展影响
- 城市增长模拟

##  经济与客流

HankPP 尝试建立距离较远的发达地区之间的出行需求。

目前考虑：

- 城市人口
- 城市发展水平
- 城市间距离
- 城际走廊
- 城际需求

本版本的想法是使人口较多、发展较高,且距离较合理的城市之间
形成更加明显的通道关系与经济走廊，类似京沪高铁。


##  数据与统计

目前包括：

- 列车运营相关数据
- 线路开通与运营历史
- 客流观测与运输反馈
- 城市间的需求统计


##  接触网与基础设施

目前包括：

- 中式化的立柱、门架和接触线
- 自动化接触网铺设与智能分组
- 单线、复线及多股道门架系统
- 车站、道岔、咽喉和终端区专用布置
- 可精细调整搭配自动化
- 不同类型的铁路/建设时期的接触网差异


##  车次与车底交路

目前包括：

- 独立于列车的交路与车次身份
- 临时换车、热备车与故障替班
- 备用车底、候选车辆
- 交路冲突与列车状态判断
- 发车信息与车底计划联动
- 多人联机下的交路同步、存档与恢复

## 中式本土化扩展

逐步添加中式内容至游中。

包括：

- 完全汉化的界面与显示内容的优化
- 中式车站大屏
