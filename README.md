# OpenTTD-HankPP 0.9-beta1


## 中文简介

OpenTTD-HankPP 是基于 JGRPP 0.73.0 开发的 OpenTTD 社区扩展版本。

本项目致力于在保持 OpenTTD 核心运输经营玩法的基础上，引入更加真实的城市经济、土地价值和区域发展模拟机制。

HankPP 当前版本为 0.9-beta1，属于测试版本。


## English Introduction

OpenTTD-HankPP is a community modification based on JGRPP 0.73.0.

The project aims to extend the economic simulation capability of OpenTTD by introducing more realistic urban development, land value evaluation and regional economic interaction mechanisms.

Version 0.9-beta1 is an experimental beta release.


---

# Features / 主要功能


## Land Value System
## 土地价值系统

HankPP introduces a dynamic land value model.

Features:

- Town land value score
- Distance-based land value evaluation
- Land purchase cost influence
- Infrastructure influence
- Urban development demand


## 城市发展模型

Includes:

- Town development demand
- Housing density adjustment
- Economic attraction between cities


## Intercity Economic Gravity
## 城际经济联系

Adds an economic gravity model between major towns.

The system evaluates:

- Population
- Urban scale
- Development level
- Land value
- Distance influence

# Compatibility / 兼容性

HankPP is not compatible with vanilla OpenTTD.

Save games created with HankPP may require HankPP to load correctly.


HankPP 不保证与原版 OpenTTD 存档兼容。

使用 HankPP 创建的存档建议继续使用 HankPP 版本加载。
